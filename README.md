# آلاء حماد — Arabic RTL website

Responsive Arabic landing page concept using a cream, sage, and muted-gold visual system.

## Project files
- `index.html` — Arabic right-to-left website
- `css/style.css` — responsive styling, mobile navigation layout, scroll reveal and image hover transitions
- `js/main.js` — mobile navigation, scroll reveal, three-image carousel
- `assets/` — 11 unique, individually generated WebP visuals

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `css/`, `js/`, `assets/`, and `README.md` to the root of your repository.
3. Open **Settings → Pages** and select the `main` branch and `/ (root)`.
4. Wait for deployment, then visit the GitHub Pages URL.
